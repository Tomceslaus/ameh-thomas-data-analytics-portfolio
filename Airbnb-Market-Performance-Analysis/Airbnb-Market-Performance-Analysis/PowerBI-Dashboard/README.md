# Power BI Dashboard – Airbnb Market Analysis

## Overview

This folder contains the Power BI dashboard developed for the Airbnb Market Performance and Listing Insights project.

## Technology
- Microsoft Power BI Desktop
- Power Query
- DAX

## Dashboard Pages

1. Market Overview
2. Pricing and Property Analysis
3. Host Performance
4. Review Activity and Guest Experience

## Analytical Activities
- Data modelling and relationship management.
- Development of calculated measures using DAX.
- Interactive data visualization.
- KPI monitoring and reporting.
- Market and performance analysis.

The Power BI report file and dashboard screenshots will be included in this folder.
