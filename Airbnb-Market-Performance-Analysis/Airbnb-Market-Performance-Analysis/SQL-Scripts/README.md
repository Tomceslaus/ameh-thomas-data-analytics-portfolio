# SQL Scripts – Airbnb Market Analysis

This folder contains SQL scripts developed during the Airbnb Market Performance and Listing Insights project.

## SQL Activities

The scripts will document the following analytical processes:

1. Database and table preparation.
2. Dataset exploration and inspection.
3. Data cleaning and transformation.
4. Data quality assessment.
5. Duplicate identification and validation.
6. Listing and review data analysis.
7. Analytical queries for business insights.

## Tools

- Microsoft SQL Server
- SQL Server Management Studio (SSMS)

## Data Sources

- Airbnb Listings Dataset.
- Airbnb Reviews Dataset.

The original datasets are not included in this repository.
