# Airbnb Market Performance and Listing Insights Dashboard

## Project Overview

This project analyses Airbnb listing and guest review datasets to explore market distribution, property characteristics, host performance and guest experience across multiple cities.

The project was undertaken as part of my data analytics development through AnalystLab Africa.

## Tools Used

- SQL Server Management Studio (SSMS)
- Microsoft Power BI
- DAX
- Power Query

## Dataset Information

- Listings dataset: 279,712 records.
- Reviews dataset: 5,373,143 records.

## Project Activities

1. Data import and database management.
2. Data cleaning and transformation.
3. Data quality assessment and validation.
4. SQL querying and analytical exploration.
5. Data modelling and relationship management.
6. Power BI dashboard development.
7. Business insights and data visualization.

## Project Objectives

- Examine listing distribution across cities and neighbourhoods.
- Investigate property types and pricing patterns.
- Explore host performance indicators.
- Analyse guest review activity and experience metrics.
- Communicate findings through interactive dashboards.

## Project Deliverables

The repository will contain:

- SQL scripts.
- Power BI dashboard file.
- Dashboard screenshots.
- Data quality documentation.
- Project findings and analytical documentation.
